# Cartpole: Neuroevolution Benchmark (GA vs NEAT)

A Java simulation of a cart balancing a single, double or triple pendulum. The cart is controlled by neural networks that are evolved with either a fixed-topology **Genetic Algorithm (GA)** or **NEAT** (NeuroEvolution of Augmenting Topologies). A headless benchmargitk compares the two approaches, and Python scripts turn the results into spreadsheets and a visualizer.

> **Disclosure:** All of the code in this repository (Java simulation, benchmark harness, Python scripts and the HTML visualizer) was generated by **Google Antigravity**.

> **Data provenance:** All data in the CSV files and spreadsheets comes from actually running the simulations through the benchmark harness. No values were entered by hand or synthesized.

## Project layout

```
src/                         Java source (NetBeans / Ant project)
benchmark_scripts/           Python helpers for summarizing results
benchmark_results_topologies/  Output data from the benchmark runs
build.xml, nbproject/, lib/  NetBeans/Ant build configuration
```

### Java source (`src/`)

| File | Purpose |
|------|---------|
| `Cartpole.java` | Interactive Swing GUI: runs the physics simulation, evolves populations (fixed-topology GA or NEAT), and displays graphs. |
| `CartpoleBenchmark.java` | Headless benchmark. Runs many independent GA and NEAT trials in parallel and writes CSV results. |
| `ExtractTopNEAT.java` | Runs NEAT on the triple pendulum and exports the top 3 champion networks to `top3_neat_triple.json`. |
| `CartAgent.java` | One cart plus its poles: physics stepping, brain evaluation and fitness calculation. |
| `SimulationContext.java` | Interface that gives agents the pole count (1/2/3), fitness options and the current start angle. |
| `Config.java` | Physics constants (gravity, pole length, etc.). |
| `Brain.java`, `NeuralNetwork.java` | Controller interface and the fixed-topology feedforward network used by the GA. |
| `NEATGenome.java`, `NEATSpecies.java`, `NEATInnovationTracker.java` | NEAT implementation: genomes, speciation and innovation tracking. |
| `GenerationData.java`, `PerformanceGraph.java`, `FitnessHistogram.java` | Per-generation statistics and the GUI charts. |

### Python scripts (`benchmark_scripts/`)

| Script | Purpose |
|--------|---------|
| `make_sheets_workbook.py` | Builds a Google-Sheets-friendly `.xlsx` workbook (stdlib only) from the benchmark CSVs. |
| `generate_neat_visualization.py` | Generates `neat_triple_visualizer.html`, an interactive SVG view of the top 3 NEAT triple-pendulum networks. |
| `show_summary.py` | Prints the aggregated `summary.csv` to the terminal. |
| `show_robustness.py` | Prints survival rates by test angle from `robustness.csv`. |

## Running

Compile and run the GUI from NetBeans, or from a terminal:

```bash
# Compile
javac -d build/classes src/*.java

# Interactive GUI
java -cp build/classes Cartpole

# Headless benchmark (all arguments optional, key=value)
java -cp build/classes CartpoleBenchmark out=benchmark_results_topologies \
     trials1=10 trials2=25 trials3=50 threads=7 maxGens=500 pop=150 maxFrames=1800

# Export top NEAT champions, then build the visualizer
java -cp build/classes ExtractTopNEAT
python3 benchmark_scripts/generate_neat_visualization.py

# Build the spreadsheet workbook and print summaries
python3 benchmark_scripts/make_sheets_workbook.py benchmark_results_topologies
python3 benchmark_scripts/show_summary.py benchmark_results_topologies
python3 benchmark_scripts/show_robustness.py benchmark_results_topologies
```

`CartpoleBenchmark` appends to existing CSVs and skips trials that have already completed, so an interrupted run can be resumed.

## Data (`benchmark_results_topologies/`)

All files are produced by `CartpoleBenchmark` (and the scripts above) from simulation runs:

| File | Contents |
|------|----------|
| `trials.csv` | One row per trial: algorithm, pole count, generations run, stop reason, CPU time, best fitness, generations to 50%/90% of the maximum, champion size, robustness. |
| `generations.csv` | One row per generation per trial: best, quartile, median and mean fitness, start angle, species count, champion size. |
| `robustness.csv` | Each trial's champion tested at a range of start angles: frames survived and fitness. |
| `summary.csv` | Per-configuration means and standard deviations aggregated across trials. |
| `top3_neat_triple.json` | The top 3 NEAT triple-pendulum champion networks. |
| `neat_triple_visualizer.html` | Interactive visualization of those networks. |
| `cartpole_benchmark_for_sheets674167.xlsx` | Most recent spreadsheet workbook, generated from the CSVs above. |

## Method summary

- **Task:** keep 1, 2 or 3 poles upright on a cart for up to 1800 frames (about 30 seconds).
- **Algorithms:** fixed-topology GA at several network sizes versus NEAT, with a population of 150.
- **Start angles:** a scaled range per pole count (1 pole: ±10°, 2 poles: ±5°, 3 poles: ±2.5°).
- **Stopping:** a plateau detector or the maximum number of generations.
- **Robustness:** final and best-ever champions are re-tested at fixed start angles outside training.
